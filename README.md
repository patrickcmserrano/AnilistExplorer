## About The Project

This project is a web application that allows users to explore anime information from an unofficial Anilist API. It is built with Astro, React, and Tailwind CSS.

### Built With

- [Astro](https://astro.build/)
- [React](https://reactjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)

## Getting Started

To get a local copy up and running follow these simple example steps.

### Prerequisites

This is an example of how to list things you need to use the software and how to install them.

- npm

```sh
npm install npm@latest -g
```

### Installation

1. Clone the repo

```sh
git clone https://github.com/patrickcmserrano/AnilistExplorer.git
```

2. Install NPM packages

```sh
npm install
```

## Usage

To run the application, run the following command:

```sh
npm run dev
```
